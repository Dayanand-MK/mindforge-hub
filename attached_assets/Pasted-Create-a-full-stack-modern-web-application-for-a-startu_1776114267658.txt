🆔 AUTO CUSTOMER ID GENERATION

Format:
MFH001, MFH002, MFH003...

Logic:

* Fetch total clients count from Firestore
* Increment count
* Generate ID with leading zeros

Example JS:
const newId = `MFH${String(count + 1).padStart(3, '0')}`;

Store this ID in database for each client.
